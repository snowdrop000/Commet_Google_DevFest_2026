## S・Qの判定条件

**Sは安全性、Qは貢献度。どちらも高いほど良い評価です。**

| 点数 | S：安全性                  | Q：貢献度              |
| ---- | -------------------------- | ---------------------- |
| 2    | 有害表現なし               | 文脈に合った明確な貢献 |
| 1    | 軽度の有害表現、または曖昧 | 貢献する要素がある     |
| 0    | 明確な有害表現あり         | 該当する貢献なし       |

### 安全性 S

Geminiは次の4項目の**有害表現の強さ**を採点します。この表では高いほど有害で、計算後のSは高いほど安全です。

| 項目           | 0点      | 1点        | 2点  |
| -------------- | -------- | ---------- | ---- |
| 人格攻撃・侮辱 | 該当なし | 軽度・曖昧 | 明確 |
| 差別・属性攻撃 | 該当なし | 軽度・曖昧 | 明確 |
| 脅迫・暴力     | 該当なし | 軽度・曖昧 | 明確 |
| 挑発・嫌がらせ | 該当なし | 軽度・曖昧 | 明確 |

```text
S = 2 − max(人格攻撃・侮辱, 差別・属性攻撃, 脅迫・暴力, 挑発・嫌がらせ)
```

### 貢献度 Q

Geminiは次の4項目の**貢献度**を採点します。

| 項目             | 0点      | 1点                      | 2点                            |
| ---------------- | -------- | ------------------------ | ------------------------------ |
| 感謝・応援       | 該当なし | 感謝や応援がある         | 文脈に合った具体的な感謝・応援 |
| 建設的な議論     | 該当なし | 意見・指摘がある         | 理由・根拠・改善案がある       |
| 質問・情報提供   | 該当なし | 話題に関連する質問・情報 | 具体的で会話を深める質問・情報 |
| ユーモア・大喜利 | 該当なし | 文脈に合ったユーモア     | 文脈を踏まえた創造的なユーモア |

```text
Q = max(感謝・応援, 建設的な議論, 質問・情報提供, ユーモア・大喜利)
```

`max`は4項目の最大値です。例：有害表現の強さがすべて0ならS=2、貢献度の最高点が1ならQ=1です。

### 最終判定

最終判定は点数に加え、確信度・文脈・根拠で決めます。確信度はGeminiの自己評価（0〜10）です。

- **安全**：S=2、確信度8以上、文脈十分。
- **有害**：S=0、確信度8以上、文脈十分。攻撃対象と直接攻撃の根拠が明確で、根拠の原文が本文に存在し、引用フラグがない。
- **要確認**：上記以外。S=1、低確信度、文脈・根拠不足などを人手で見直す対象として残す。

## XP・コイン

投稿成功を仮定し、TypeScriptの固定ルールで計算しています。Geminiは報酬を決めません。

| 最終判定       | Q=0        | Q=1        | Q=2         |
| -------------- | ---------- | ---------- | ----------- |
| 安全           | 2XP・1.0倍 | 6XP・1.5倍 | 10XP・1.5倍 |
| 有害           | 0XP・0倍   | 0XP・0倍   | 0XP・0倍    |
| 要確認（暫定） | 2XP・1.0倍 | 2XP・1.0倍 | 2XP・1.0倍  |

獲得コインは仮コイン×倍率の端数切り捨て。CSVでは仮20枚からの獲得数も示します。実ユーザーへの付与はありません。

## 架空文脈100件の概要

2026-11-07、`gemini-3.5-flash-lite`で100件を評価しました。感謝・応援、改善提案、正当な批判、質問・情報、ユーモア、短文、侮辱、有害表現、引用・皮肉、文脈依存の10種類を各10件用意しています。

**安全72件・有害21件・要確認7件。** Sは2点74件／1点5件／0点21件、Qは2点44件／1点32件／0点24件です。100件すべて評価完了。一時エラー2回は再試行で復帰し、平均API応答時間は約2.27秒でした（間隔・再試行の待ち時間を除く）。

[100件の結果CSV](fictional-context-100.csv)には本文・文脈・8項目・S/Q・報酬・判定理由を掲載しています。人手判定・人手S・人手Qは未設定です。数式と誤認される文字列には先頭に`'`を付けています。

## 実動画50本の概要

2026-11-08、同じモデルで、実際のYouTube動画50本と自作コメントを評価しました。前回10件を保持し、40本を追加しています。要求区間は冒頭から最大2分、追加40本は最大90秒です。

**対象50件のうち、評価採用41件（安全34件・有害4件・要確認3件）、出力検証などによる未確定9件です。** 未確定ケースにはXP・コインを計算していません。

| 実動画とテストコメント                                |   S |   Q | XP・コイン倍率 |
| ----------------------------------------------------- | --: | --: | -------------- |
| ホームラン動画（real-01）：「その一発、最高だった。」 |   2 |   2 | 10XP・1.5倍    |
| 暴行の報道（real-02）：「その一発、最高だった。」     |   0 |   0 | 0XP・0倍       |
| H3ロケットの動画（real-07）：「なるほど。」           |   2 |   1 | 6XP・1.5倍     |

別の暴行報道への同じ文（`real-27`）はS=0でも、直接攻撃・根拠の条件で「要確認」となり暫定2XP・1.0倍でした。Sだけで有害判定・0XPが確定する制度ではない点も相談が必要です。

同じ文が動画の文脈で判定を分けた例がありました。一方、短い相づちへの加点や、根拠時刻の不整合は残っています。[50件の結果](real-video-50.md)と[両実験の相談点](review.md)で確認できます。

人手の正解ラベルは未設定で、正解率は未測定です。100件実験とは入力・プロンプトが異なるため、動画入力だけによる改善とは断定できません。報酬は投稿成功を仮定したシミュレーションで、実際のコメント投稿・Firestoreへの付与は行っていません。
