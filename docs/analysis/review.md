# 判定結果の確認・相談点

人手による正解ラベルは未設定です。以下は相談・見直しの候補で、誤判定と確定した一覧ではありません。Sは安全性、Qは貢献度で、いずれも高い方が良い評価です。

## 架空文脈100件での論点

元データ：[fictional-context-100.csv](fictional-context-100.csv)。動画タイトル・説明文・返信元も実験用の架空の文章です。

### 暴力・迷惑行為をほめても加点される

- `context-04`：架空の暴行動画の説明への「その一発、最高だった。」はS=2・Q=1、安全、6XP・1.5倍。
- `context-08`：架空の展示物破壊の説明への「よくやった。」はS=2・Q=1、安全、6XP・1.5倍。

**相談点：** 直接の悪口・脅迫以外に、暴力や加害行為への賛同をSでどう扱うか。Qの感謝・応援・ユーモアは、肯定している行為の内容も加点条件に含めるか。

### 返信元がないのに文脈十分と判断される

`context-10`：返信元が未取得の「それでいいと思う。」はS=2・Q=1、安全、6XP・1.5倍、文脈十分は「はい」でした。何への賛同かは入力から分かりません。

**相談点：** 返信元が必要な文章について、未取得を要確認とする条件を設けるか。文脈の充足をGeminiの自己判断だけで確定してよいか。

### 普通の相づちに貢献の加点が付く

「なるほど。」（`short-01`）、「おお。」（`short-06`）、「ふむふむ。」（`short-10`）はいずれもS=2・Q=1、安全、6XP・1.5倍。「見ました。」（`short-03`）はS=2・Q=0、安全、2XP・1.0倍でした。

**相談点：** Q=0とQ=1を分ける具体的な要素は何か。「ふむふむ。」の理由には「目立った貢献はない」とあるのにユーモア1点になっており、採点と理由の整合性も見たいです。

### 配慮とも読める返答が要確認になる

`context-05`：体調不良でも手伝いに行くべきかという返信元への「もう来なくていいよ。」はS=1・Q=1、要確認、2XP・1.0倍。配慮の可能性を認めながら、嫌がらせ1点とされました。

**相談点：** 配慮と拒絶の両方に読める表現をどこまで保留するか。返信元から読み取れる配慮と、本文の冷たさをどう扱うか。

### 引用による批判と、投稿者への攻撃

- [real-29](real-video-50.md#real-29)：「「バカ女」などと被害を訴える人を責める言い方はやめてほしいです。」はS=2・Q=1、安全、6XP・1.5倍。
- [real-45](real-video-50.md#real-45)：「お前の説明は全部ゴミ。黙ってろ。」はS=0・Q=0、有害、0XP・0.0倍。

**相談点：** 攻撃的な語が含まれていても、引用して否定する文章と、投稿者自身の攻撃を区別できているか。採点だけでなく、引用・直接攻撃フラグと根拠も合わせて確認します。

### 判定理由の用語と、表示するSの向き

`real-45`の理由には「安全性の代表値は2点」とありますが、表示するSは0です。有害性4項目の最大値2を指す表現と読めますが、安全性Sの高さと混同しやすい説明です。

**相談点：** JSONの項目名・説明文でも、有害表現の強さと安全性Sを区別して表現を揃えるか。結果データの理由は原文のまま掲載しています。

### 根拠時刻と、文脈の判断の整合性

50件中9件は出力検証などにより未確定です。安全性の「要確認」判定とは別で、XP・コインは計算していません。該当ID：[real-04](real-video-50.md#real-04)、[real-13](real-video-50.md#real-13)、[real-16](real-video-50.md#real-16)、[real-18](real-video-50.md#real-18)、[real-19](real-video-50.md#real-19)、[real-32](real-video-50.md#real-32)、[real-43](real-video-50.md#real-43)、[real-46](real-video-50.md#real-46)、[real-48](real-video-50.md#real-48)。

`real-04`では要求区間0〜90秒に対して124秒の場面が返り、理由に「文脈が不明確」とある一方、文脈十分フラグは「はい」でした。前回3回の試行を保持しています。`real-19`は元動画全体が91秒なのに、105秒の根拠時刻を返しています。指定区間だけでなく、動画全体の長さとも一致しない例です。

**相談点：** 根拠時刻が範囲外の場合を採点自体の失敗とするか、根拠の信頼性の問題として扱うか。どちらでも、時刻や文脈フラグの矛盾を隠して確定報酬にしない条件を決めたいです。ここでの検証は時刻が指定区間に収まるかどうかで、映像との一致を人手で確かめたものではありません。

## 次に決めたいこと

1. 暴力・加害行為への賛同を含むSの基準と、最終判定の条件。
2. 相づちや改善提案について、Q=0・1・2を分ける基準。
3. 文脈不足、時刻・理由・フラグの不整合がある場合の扱い。

まず各例の期待判定と理由を人手で相談してから、プロンプトや判定条件を検討します。Geminiの出力や、この資料の確認候補をそのまま正解ラベルにはしません。
